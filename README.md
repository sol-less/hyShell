## About

**hyShell** is a simple Quickshell configuration inspired by Google's **Material Design 3**. It's built to be visually fluid while keeping resource usage minimal and performant. 

* **Target OS:** Arch Linux *(recommended)*
* **Compositor:** Hyprland

---

## Dependencies

Make sure you have the following packages installed before running **hyShell**:

* `quickshell-git`
* `matugen`
* `git`
* `yay` *(or your preferred AUR helper)*

---
